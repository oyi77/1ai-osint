## Honest methodology — read before comparing

1. **Different targets per tool.** `octocat` is a real, active GitHub user, so
   username-enumeration tools (sherlock, maigret, 1ai-osint) all ran against
   it. holehe only accepts an email, so it ran on `john.doe@example.com`
   (a reserved example address — no real accounts expected). theHarvester
   targets domains, so it ran on `example.com`. These runs are **not** a
   head-to-head race; they are per-tool smoke evidence.
2. **Finding counts are tool-dependent.** Each count is parsed from the
   tool's own output format (sherlock/maigret hit markers, holehe `used`
   accounts, 1ai's structured findings) and the semantics differ — e.g.
   maigret counts one `[+]` per platform hit while 1ai groups related
   findings and dedupes. A higher number does **not** mean "more correct".
3. **1ai ran keyless-only modules** (0-API priority): gitleaks,
   data_leaks, people_finder, phone_finder, crypto_privatekey. It reached
   120 findings in 57.9 s with zero API keys configured, on a single
   invocation covering breach, people, phone, secret and crypto surfaces —
   capabilities the other tools do not bundle (see the capability matrix).
4. **theHarvester timed out** at 120 s on `example.com` with 0 findings —
   that reflects a slow/no-output run on that target, not a verdict on the
   tool.
5. **Live sources drift.** Regional availability, rate limits and upstream
   changes mean these numbers will not reproduce exactly on another day.

## What this does and does not prove

- **Shows:** that 1ai-osint's keyless module set produces structured,
  severity-scored findings on a real target with no API keys; that the
  bundled run is time-bounded; that sherlock/maigret/holehe are invokable
  from the harness; and that per-tool receipts are preserved.
- **Does not prove:** that 1ai-osint is "the best OSINT tool in the world".
  Cross-vendor superiority claims would require identical targets, identical
  output semantics, a sustained live corpus, and an independent third-party
  audit — none of which this folder asserts.
